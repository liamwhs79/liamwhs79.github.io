Reply ready

Send this reply back to the person who created the invite. They paste it into the same box above and tap Accept / Connect.

Why is the shared invite longer than the Berry code?
The short BERRY-XXXX-XXXX code is a verification code. A truly short code-only connection would need a small Berry Haven signalling server to look up the WebRTC handshake. This standalone one-file build keeps that service out of the equation.

Local privacy

This account's messages, boundaries, game progress and settings are stored in this browser on this device. Nothing is uploaded to a Berry Haven server by this standalone file.

Account & Local Data

These controls only affect this browser on this device. They do not erase anything already stored on a partner's phone.

Remove this account's local data Keeps the account and password, but clears its messages, attachments, boundaries, plans, Berry Adventures, game progress, Berry Wallet, Prize Garden unlocks and other saved app data. It starts the account fresh.
Delete this local account Deletes this account's login, password hash, Berry combination and all of its Berry Haven data from this device, then returns to the login screen.
